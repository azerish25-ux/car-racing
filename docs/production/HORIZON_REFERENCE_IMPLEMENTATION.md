# Horizon reference implementation record

## Scope and status

This change develops the original **MOTOBOUND Festival / Solvane** open world using the supplied 100-image reference pack. It extends the existing TypeScript/Three.js game rather than importing the reference scenes. Every numbered image was opened and inspected individually: 37 vehicle images, 25 environment/lighting images, and 38 gameplay/UI/mixed images. The merged review contains IDs **001–100 exactly once**, with no missing or duplicate IDs.

The source images are a mixture of vehicle portraits, racing pictures, environments, actual HUD/menu views, promotional illustrations, sales graphics and hardware infographics. The rows below retain that distinction. A still image can establish visible shapes, material relationships, composition and interface hierarchy; it cannot establish measured tyre forces, engine output, network functionality, licensed-content entitlement or frame rate.

**Acceptance status:** implementation, per-image review, representative vehicle/world rendering, the real browser driving/event journey, normal application entry, focused regressions and the Festival closeout guarded production build are complete. The [validation report](HORIZON_UPGRADE_VALIDATION.md) records the exact results, each capture's source identity, the subsequent integrated build identity, screenshots and remaining hardware/playtesting limits. Its sections 8–10 separate the validated compositions that preserve concurrent MotoGP changes from the earlier Festival closeout captures; the original images and capture JSONs retain their original fingerprints. This document does not claim pixel equivalence to a commercial game or perfect behavior on all hardware. The per-reference implementation links identify inspectable work and explicit limits.

No reference screenshot is shipped as a game texture. The new signs, scenery meshes and vehicle detail geometry are original. The source archive credits Microsoft / Xbox Game Studios / Playground Games and lists [Forza Media](https://forza.net/media) as its source page. Each numbered link below uses the archive’s exact `downloaded_from` URL; its link title preserves the supplied archive filename. These are source-attribution links, not assets fetched by the game.

Blender was not required for this pass. Extending the existing procedural geometry keeps vehicle damage groups, quality controls, road heights and collision-backed building footprints consistent with the runtime. The existing licensed photographic vegetation library is reused where available; the generated meadow remains a fallback.

## Explicit scope limits

This pass does not recreate the reference game’s licensed cars, branded stores, Japanese map, seasonal reward service, premium packages, multiplayer modes, stadium crowds, snow-plough simulation, fireworks system or a boat-driving mode. Existing terrain, tyre/suspension dynamics, photographic asset provenance and damage systems are retained where the change relies on them. The work is a significant original environment, vehicle presentation and festival-play improvement, with inspectable code and bounded rendering additions. Final visual quality and playability remain matters for the integrated evidence and target-device testing; “perfect” is not a testable claim established by the source images.
