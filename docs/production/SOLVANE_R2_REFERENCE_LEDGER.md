# Solvane R2 — individual 100-image continuation ledger

This is the resumed R2 street/contact/pace pass, not a relabelling of the earlier completed `2cacf1d` runtime or its tests. All 100 numbered images in the supplied ZIP were decoded and hash-checked and were revisited on ten numbered contact sheets. This is **not** 100 full-resolution matched before/after game captures. Original filenames, source URLs and limits remain in [the initial ledger](HORIZON_REFERENCE_IMPLEMENTATION.md) and [the existing integrity record](solvane-reference-integrity.json).

Archive SHA-256: `fa010b4b80fe39eb68b51d67bac06de1f3845619ab4ed546083d3caaffc65e59`. The supplied pack identifies mixed official media; it does not prove that every frame is a PS5 gameplay capture. No supplied media is embedded in the generated assets or this public ledger.

**STREET** = original Blender canopy/condenser/drain construction and bounded instancing (`authoring/solvane/build_street_kit.py`, `src/rendering/open-world/street-details.ts`). **CONTACT** = physical-contact-based approximate ground darkening (`src/rendering/open-world/contact-shadows.ts`). **PACE** = route/grip/grade/wetness-aware advisory, separate from the existing score HUD (`src/rendering/open-world/pace-coach.ts`, `horizon-guidance.ts`, `src/ui/festival-hud.ts`). Shared codes describe a shared implementation, not a separate feature per image. They do not claim literal object replication or reference parity.

“Retained interpretation” preserves the earlier row and its explicit limitations; it is not a fresh completion claim. “Context only” does not fabricate a gameplay requirement from a hardware, sales or promotional panel. Particular car shells, complex interiors, unique architecture, vegetation, terrain and hardware performance remain outside this R2 continuation.
