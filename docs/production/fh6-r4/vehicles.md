# FH6 reference pass r4 — festival vehicle visuals (agentE)

Scope: the festival's player car and rivals (shared catalogue bodies) and the
ambient traffic. Circuit, MotoGP and motocross bodies are not touched: every
hero-car change is installed by `installFestivalFinish`
(`src/rendering/open-world/festival-car-finish.ts`) from `FestivalCars`'
`VehicleBodies.onBuild` hook, which now also receives the built body and its
entrant id; the circuit renderer's hook still reads only the root and
installs nothing (asserted in `tests/festival-vehicle-finish.test.ts`: plates,
running lights, glazing, rims and paint of a plain `VehicleBodies` body are
unchanged).

Each row: what the reference shows (measured on the 1920 x 1080 image; colours
are sRGB hex read from flat-lit areas), what this pass implemented, and what
is still missing. Plate size, lamp heights and body sizes use real-world values
where the photo does not resolve them (Japanese plate 330 x 165 mm; kei
3.40 x 1.48 m).

## Ambient traffic (`src/rendering/traffic-cars.ts`)

Japanese everyday traffic (refs 006 kei truck; 030/038/056/059/061 streets):
six body types authored at real size — saloon 4.85 x 1.80 x 1.45 m, compact
hatch 4.00 x 1.70 x 1.52, kei tall wagon 3.40 x 1.48 x 1.76, kei truck
3.40 x 1.48 x 1.78 (near-upright cab, drop-side bed, guard frame), minivan
4.70 x 1.72 x 1.86, cab-over light truck 6.0 x 1.95 x 2.2. Each traffic
machine is drawn as a body whose real plan is within 0.26 (summed log ratio)
of its collision box (`trafficBodiesFor`); the body is stretched only in plan
to the collision footprint so the visual matches what the player hits, heights
stay real, and a vertex correction keeps wheels round and rolling (on the
interpolated traffic time). Paint mix (`TRAFFIC_PAINT`): white/pearl 34 %,
silver/grey 22 %, black 16 %, then navy, beige, red, brown, pale blue, yellow
and green. Japanese plates from the same atlas (yellow on kei types), rear
plate lit at night. Draws: one instanced draw per body type present (per-vertex
material classes: paint, glass, trim, chrome, rubber, alloy, lamps, plates),
one contact-shade draw for the field, and at night one halo draw.
