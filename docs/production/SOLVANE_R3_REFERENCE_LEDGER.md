Disposition counts: **58 partial technique transfers**, **36 reviewed with implementation still outstanding**, and **6 promotional exclusions**. The JSON companion preserves each image's original filename, byte count, SHA-256, source provenance, specific code mapping and remaining work. The reference photos themselves are not redistributed.

## Meaning of the application labels

**Architecture** maps to `build_joinery.py`, `facade-layout.ts`, `facade-joinery.ts` and `buildings.ts`. It means inset panes and reveals, manufactured frame and sill shapes, shutters, plaster/brick/stone and window-light separation in **original Solvane** architecture—not reproduction of a depicted Japanese street or commercial shop.

**Motion** maps to `chase-dynamics.ts` and `festival-renderer.ts`. It means a restrained chassis-motion-driven camera, not a replacement vehicle mesh, motion blur, or reference-matched race.

**Drift advice** maps to `drift-feedback.ts`, `festival-hud.ts` and `free-roam.ts`. It means observed angle and direction with guidance matching the existing admission thresholds. Component HUD evidence uses synthetic cases; the actual worker/input session is separately identified. No source-image score is fabricated.

Native Blender `reference_ids` are a study list, **not** proof that every listed requirement is implemented. All remaining items below are explicit production debt.

## Evidence and acceptance scope

The seven isolated before/after building views use the same camera, selected actual regional building, lighting and exposure for each pair. They demonstrate silhouette, recess, frame, material and night-window differences, not full-world lighting quality. The full FestivalSession captures use real production workers, scene systems and asset bytes. Network navigation is blocked in this environment, so an explicitly documented fixture bridge provides the same disk bytes. This is not an HTTP, CDN, secure-origin or deployment test.

The supplied images remain owned by the holders named in their original manifest. They were used for visual analysis; this delivery contains original geometry/code and test captures of MOTOBOUND, not extracted Forza assets or copied branding.
