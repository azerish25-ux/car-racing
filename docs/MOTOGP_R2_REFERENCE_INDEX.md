Each row corresponds to one supplied numbered image. These are observations and scoped implementation actions, not claims that every depicted scene was recreated. The [complete machine-readable ledger](motogp-reference-r2.json) includes every SHA-256, source details, observations, applicable code cross-references and limitations. Every partially applied row links relevant shared checks. See the [delivery report](MOTOGP_R2_DELIVERY.md) for changes, measured results and screenshots.

All 100 payload hashes were verified. Dispositions: 74 partially applied, 10 existing support reviewed, 16 context only.

**Verification scope:** Linked tests exercise shared production components and regressions; they are not automated comparisons with each reference picture and do not certify its complete scene, full wet/night-race visual acceptance or visual parity. Context and existing-support rows with empty validation lists claim no additional per-image verification.

**Disposition scope:** Partially applied rows identify specific transferred cues. Existing-support rows review a primary feature that was already present. Context-only rows leave their primary scene, discipline or mode outside this revision. Shared R2 improvements mentioned in existing-support or context rows are explicit cross-references to applied rows, not claims of a new scene or mode.
